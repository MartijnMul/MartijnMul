### Martijn Mullié

I build software end to end, from the first sketch to production:
web platforms, voice AI, tools for the factory floor, and small
open-source apps. Most of it is client and company work in private repositories;
the open-source part lives here.

**Open source**

- [Get Caffeinated](https://github.com/MartijnMul/get-caffeinated): keeps
  your Mac awake from the menu bar, until a time, until unplugged or until
  you leave. Swift.
- **Allstill** *(in development)*: self-hosted monitoring for cron jobs,
  backups and websites, with a macOS menu bar app.
- **PlainSign** *(in development)*: get contracts signed on your own server,
  with evidence anyone can check. Go.
- **Plaincontrol** *(in development)*: open any project from the keyboard
  in your terminal, editor or Finder, with windows placed in columns across
  your screens, and every running Claude Code session one key away. Swift.

**Work**

- **Voice AI for healthcare**: telephony platform, knowledge base and
  guideline retrieval for an AI assistant that answers calls for GP and
  physiotherapy practices, at [Plainwise](https://plainwise.com).
- **E-commerce**: door configurator with live pricing, checkout and order
  handling, live at [dedeurenwinkel.nl](https://dedeurenwinkel.nl).
- **Manufacturing**: production dashboard, label printing and a desktop app
  for measurement files, for a door factory.
- **Kanban with bets**: project board, sales pipeline and service desk in
  one, run by people in a realtime web app and by AI agents through MCP.
  Several teams work on one installation.
- **Agent tooling**: MCP servers for Gmail and Slack, Claude Code plugins,
  and Pivot, inline review comments for Markdown documents.

**On the side**

- [Gym Assist](https://gym-assist.com): training plans and workout tracking.
  The next version builds plans from training science and fixed programming
  rules instead of an LLM.
- [moetikmijnbandenwisselen.nl](https://moetikmijnbandenwisselen.nl): when to
  switch to winter tyres, per 10 km, from weather ensembles.
- **Imperium** *(in development)*: a massive online game set in Roman times.

**Tools**: Swift · TypeScript / Next.js · Python / FastAPI · Go · Rust / Tauri · PostgreSQL · Redis
